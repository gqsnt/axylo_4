# Axylo 1.0 performance budgets

Baseline measured on 2026-11-21 and 2026-11-22 using headless Chrome 158.0.8127.36 with software rasterization. Timings use the sealed artifact `20261119T091624Z-b643862f-b78698`, SVG marks, default chart options and the accessibility layer. The table shows the one-minute load range at the start of the timed blocks. P6 uses the packed consumer bundles, measured on matching library source.
