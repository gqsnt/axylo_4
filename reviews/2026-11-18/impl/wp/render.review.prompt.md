Find defects, most important first:
1. **Wrong pixels.** Path pen lifts (leading, trailing and consecutive NaN pairs; a single-vertex subpath); AreaMark runs (index arithmetic on `runs`, reversed lower boundary, zero-count runs, shared boundary arrays); rect variants; each marker shape's geometry and size; arcs (clockwise from 12 o'clock; a full-circle slice; a zero-width slice; the constant-width gap at inner and outer radius); rule snapping at device pixel ratios 1, 1.5, 2, 3; clipping (which roles escape the clip); dash selection; overlay clearing; differences between the two renderers that a coarse pixel-grid comparison would not catch.

4. **Theme.** The scheme decision against spec L4 in each case (`color-scheme: light`, `dark`, `light dark`, unset, `only dark`; text color fallback; `--axylo-background`; an ancestor whose theme differs from the root); forced colors and `prefers-contrast`; the probe used to resolve colors (removed afterwards? forces layout on every call? works when the chart is detached or `display: none`?); `watchTheme` (cleanup; coalescing; what it misses); `ensureStyles` (duplicate adoption, documents without `adoptedStyleSheets`, shadow roots, detecting an already loaded stylesheet); the default stylesheet (cascade-layer behaviour against a page's own rules; anything that could leak out of `.axylo` and restyle the host page).
5. **Text layer.** Anchor, baseline and rotation math against `PlacedText.box`; element reuse; reads between writes; `textContent` only; user text-spacing overrides; late-loading fonts.
6. **Color math** in `theme/color.ts`: every syntax a computed style can return (`rgb()`, `rgba()`, space-separated forms, percentages, `color(srgb …)`, `color(display-p3 …)`, `transparent`, system colors), luminance and contrast formulas, alpha.
7. **Tests that do not test**, and important behaviours with no test.
