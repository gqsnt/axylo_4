## 2. Defects introduced by this round

1. **AX160 can keep a fixed-height chart redrawing.** Give y an explicit `[0, 10]` domain and a tick formatter that throws at 2. At a height where the disclosure note forces sparser ticks, the note removes tick 2, which removes the note, which brings tick 2 back. The Node host alternated between 121 px and 101 px plots with simulated resize notifications. Keep tick-only AX160 as a diagnostic with effect `none` so the note cannot change the fit. [controller.ts:1552](/home/canarit/projects/axylo/packages/axylo/src/core/controller.ts:1552), [chart.ts:239](/home/canarit/projects/axylo/packages/axylo/src/core/chart.ts:239)
2. **A pinned scatter pager can repeat page one.** At DPR 1, pin a point at horizontal offset 0.8 px. Append eight at offset 0 and the latest at 0.4 px, all at the same y with fixed axes. The redraw takes the middle point’s count of ten but makes the pinned point the paging anchor. That anchor has only two members, so `+2 more` returns to page one. Keep the lookup’s anchor, sample, and count together and track the pinned ref separately. [interaction.ts:1947](/home/canarit/projects/axylo/packages/axylo/src/dom/interaction.ts:1947), [interaction.ts:778](/home/canarit/projects/axylo/packages/axylo/src/dom/interaction.ts:778)
3. **A press can disappear during a resize.** Press Q3’s floating row, shrink the chart into strip mode while holding it, then release over the new Q3 strip button. The redraw deletes the captured entry, so no selection fires. Keep the row’s semantic identity for the life of the pin and resolve it in the current presentation on release. Bind click suppression to that press. [interaction.ts:2097](/home/canarit/projects/axylo/packages/axylo/src/dom/interaction.ts:2097), [tooltip.ts:218](/home/canarit/projects/axylo/packages/axylo/src/dom/tooltip.ts:218)
4. **An append can undo a narrow scatter zoom.** On the R8 fixture, zoom to `[-1000, 1500]` and append x=1600. The window jumps to `[-500, 2000]` and admits the new point. I observed this in Node. Preserve the drawn bounds for the current zoom across appends and extend them when the data grows. [controller.ts:504](/home/canarit/projects/axylo/packages/axylo/src/core/controller.ts:504)
5. **Changing `x.format` leaves stale keyboard text.** Focus Q1 in the default all-series mode and change its formatter to say “Quarter Q1.” The tooltip updates, but `aria-valuetext` keeps “Q1” because the comparison key only keeps raw x. Include both raw x and formatted x in the key. [focus.ts:176](/home/canarit/projects/axylo/packages/axylo/src/core/focus.ts:176), [interaction.ts:948](/home/canarit/projects/axylo/packages/axylo/src/dom/interaction.ts:948)
6. **Scatter zoom rebuilds indexes for off-screen data.** Zoom a multi-month scatter to one day, with more than 32 measurements sharing a date. Each zoom or pan rebuilds the full-series row map and allocates a reverse grid index for all points. Reuse row indexes across views of the same frame and size the grid index to visible ranges. [scatter.ts:40](/home/canarit/projects/axylo/packages/axylo/src/lookup/scatter.ts:40), [scatter-grid.ts:74](/home/canarit/projects/axylo/packages/axylo/src/lookup/scatter-grid.ts:74), [controller.ts:1568](/home/canarit/projects/axylo/packages/axylo/src/core/controller.ts:1568)
