## Not testable as written

- F9 "after which combinations repeat": describes what is allowed after 32; a test could only pin the implementation's chosen cycle.
- F12 "worded so it reads correctly for any count": a language judgement. Tests check the exact text for 1 and 3 (and the template).
- F6 "ticks may be compact (50K)": permissive. Checked with an author compact tick format (Node) and the default compact form at a million or more (formatter unit test).
- Spec 3.5 "Warning: … the reader sees the note in F12" against F12's narrower "values left out or changed": AX110, AX130, AX140, AX141, AX150, AX151, AX152 are warnings with no note. The tests follow F12 (AX140 and AX150 assert no note; a tick formatter's AX160 asserts no note). The registry rows should say which warnings carry the note.
- F10 for compact: "tooltip, table and announcements" do not exist on a compact chart; the test reads it as the summary (its title says so).
- F6 "page locale": the Node suite takes the locale from a host stub; only a browser test can show it comes from the page.
- The registry names no chart types per code; the applicability judgements listed under F3 are inferred.

The cases register with no title, so a describe-prefix citation can never pass (by design) and no exact title exists. Writing the list inline would make the test citable and lift F9 line and area.
- The checker does not check `kind` against the file: the old F8 row cited Node unit tests in `format/index.test.ts` as `browser`, which would wait for a Chrome result that a Node run never gives.
- The F3 registry rule only collects `AX\d+` from cited titles, so a title that names a code satisfies it whatever the test asserts (example: the AX130 case above).
- `validate.mjs` prints cell statuses only when the whole merged matrix has no structural error; while other families are in progress it prints none. Statuses here come from the real checker on a copy where only these rows cite tests.
- Negative controls these rows depend on: painted-colour sampling (`paintedSeries`/`inkColor`, A5 line control) for the A5 palette and AX141 citations and the C4 compact bar texture. No negative control covers the helpers behind T-limit (`cues()`), F8 (`ring`/pixel sampling at mid angles), F12 (`noteState`), F10 (bar sides from `shapes`) or L8 (`plotDrawn`).
