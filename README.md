# Axylo

Everyday charts for web apps and dashboards: faithful to the data, readable everywhere, accessible by default, and honest when the data is wrong.

Status: design, revision 2 (2026-11-18). No library code exists yet. Revision 1 was reviewed by three independent reviewers; revision 2 answers them and has not itself been reviewed.
